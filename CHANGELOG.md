# Changes

## 1.0.0

First release.

- Wilson ranges for every variant's rate at 90, 95 or 99 percent confidence.
- A verdict against the success line: passes, fails or undecided, with the visitors still needed when undecided.
- Every pair of variants compared with Newcombe's method; a leader only when the difference clearly excludes zero.
- Cost per action when the traffic cost is given.
- Reports as text, Markdown, JSON and CSV; `--fail-on-fail` for use in a pipeline.
- Release packages come with a CycloneDX SBOM, SHA-256 checksums and a build provenance attestation.
